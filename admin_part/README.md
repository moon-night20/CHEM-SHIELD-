# Admin console

From the repository root, create users with `chem_shield_p1/.venv/bin/python -m admin_part.manage_users create USER --role administrator`, then run `chem_shield_p1/.venv/bin/python -m admin_part.app`. The console reads the P4/P5 JSON files under `out/` and stores decisions in its local SQLite database.

If `CHEM_SHIELD_SECRET_KEY` is unset, the console generates a random key at
each start; browser sessions reset when the process restarts. For a stable
local demo, set an example-only value before starting the console:

```bash
export CHEM_SHIELD_SECRET_KEY="demo-only-session-key"
```

P6's operator-confirmation token is generated by the HMI per process and
rotates when the HMI restarts. P1 ingest likewise requires
`CHEM_SHIELD_INGEST_TOKEN`; if unset, the HMI generates an unpredictable
per-process token without logging its value. To enable P2/P5 publishing, set
the same example-only `CHEM_SHIELD_INGEST_TOKEN="demo-only-ingest-token"` in
the HMI and publisher environments. Do not use these demo values as real
secrets.

All actions are human decisions recorded locally. No response is executed.
