# Part 3 evaluation results

`heldout_scenario_evaluation.csv` and
`heldout_evaluation_summary.json` are generated by
`python3 -m chem_shield_p3.scripts.evaluate_heldout`. The experiment trains on
P1-simulated normal runs only; the full `stealthy_in_range` and
`slow_gradual_drift` scenarios are held out for evaluation. The normal
evaluation stream is one simulated hour (7,200 readings at 0.5 seconds per
reading). Detection rates and latency therefore describe generated simulator
data, not real equipment.

Regenerate the normal and scenario inputs and evaluation output with:

```bash
python3 -m chem_shield_p3.scripts.generate_normal_data --samples 6000 --seed 42
python3 -m chem_shield_p3.scripts.generate_test_scenarios --seed 2026
python3 -m chem_shield_p3.scripts.evaluate_heldout
```

| File | Contents |
| --- | --- |
| `heldout_predictions.csv` | Per-reading predictions for normal telemetry and the two complete held-out attack scenarios. |
| `heldout_scenario_evaluation.csv` | Per-scenario detection rate, detection delay in samples and seconds, and false alarms/hour on normal data. |
| `heldout_evaluation_summary.json` | Training/evaluation protocol, headline metrics, per-scenario results, and synthetic-data limitations. |

`historical_headline_metrics.csv` and older `hard_scenario_*` outputs are
retained as historical artifacts only. They use superseded schemas or
evaluation protocols and must not be used as the current model headline.
