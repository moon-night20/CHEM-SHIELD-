    OFFLINE FILE-BACKED CHAIN

    A short map of the existing sequential pipeline. Choose a stage to jump to its role; this guide does not start a run.

    Network replay Physical model Risk correlation OT validation
    Network input sanitized event fixture → P2 Telemetry input local CSV → P3 and P5
    P2 · NETWORK

    Replay & score

    Scores the supplied synthetic network events and selects anomalous assets and time window.

    Output: scored network events + handoff
    asset / time handoff→
    P3 · PHYSICAL

    Model scoring

    Uses that window to select telemetry and score it with the saved physical anomaly model.

    Output: physical anomaly events
    P2 + P3 events→
    P4 · CORRELATION

    Correlate & rank

    Matches network and physical events by asset and time, then calculates incident risk.

    Output: correlated incidents
    incident window→
    P5 · OT VALIDATION

    Check & report

    Validates incident-window telemetry with sensor checks and configured rules.

    Output: validation report
